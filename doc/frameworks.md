# Frameworks and Responsibilities

| Framework/library | Responsibility |
|---|---|
| ASP.NET Core | HTTP, DI, middleware, health checks, and Swagger |
| EF Core/Npgsql | PostgreSQL persistence and migrations |
| MediatR | Command/query dispatch |
| AutoMapper | Mapping between contracts and use cases |
| FluentValidation | WebApi and Application validation |
| JWT/BCrypt | Authentication and secure password storage |
| Serilog | Structured logging and request logging |
| Rebus/RabbitMQ | Integration-event publishing |
| xUnit/NSubstitute/FluentAssertions | Unit testing |
| Testcontainers | Real PostgreSQL/RabbitMQ dependencies in tests |
| Angular | Web frontend |
