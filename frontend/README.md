# Ambev Sales Frontend

Frontend Angular standalone, strict e modular para a API de avaliação Ambev.

## Executar

```powershell
npm.cmd install
npm.cmd start
```

O proxy aponta `/api` para `http://localhost:5119`. Inicie o backend antes de acessar `http://localhost:4200`.

## Verificar

```powershell
npm.cmd run lint
npm.cmd test
npm.cmd run build
```
