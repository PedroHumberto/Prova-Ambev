# Ambev Sales Frontend

Standalone, strict, and modular Angular frontend for the Ambev evaluation API.

## Executar

```powershell
npm.cmd install
npm.cmd start
```

The proxy points `/api` to `http://localhost:5119`. Start the backend before accessing `http://localhost:4200`.

## Verificar

```powershell
npm.cmd run lint
npm.cmd test
npm.cmd run build
```
